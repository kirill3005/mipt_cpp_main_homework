Домашнее задание 1 по C++

Сборка через cmake:

cmake -S . -B build
cmake --build build

После этого в папке build появятся task1, task2, task3, task4. Все читают ввод из консоли, можно так: ./build/task1 < input.txt

task1 - дневник погоды. На вход N и потом N температур, выводит среднюю, минимум с максимумом и сколько дней было ниже нуля.

task2 - копилка. Команды deposit k, withdraw k, balance, reset, stop. От себя добавил double, она удваивает сумму.

task3 - табло 5 на 10. Команды clear, put x y c, text x y слово, print, quit.

task4 - сортировка таблиц по сумме элементов. Сначала вводится количество таблиц, потом размеры каждой (строки и столбцы), потом все числа подряд. Выводит таблицы по возрастанию суммы, перед каждой ее сумму.
